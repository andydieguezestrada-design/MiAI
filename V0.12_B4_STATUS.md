# MiAI V0.12-B4 — Real Embeddings

Status: **Release Candidate / experimental**. V0.11.1 remains the last stable baseline until real-provider quality validation is completed.

## Included
- OpenAI-compatible `/embeddings` provider.
- Single and batch embedding parsing with ordering and dimension validation.
- Persistent chunk embeddings in SQLite.
- Semantic + lexical hybrid retrieval.
- Semantic candidate pool increased to 5000 chunks/project.
- Reindex endpoint: `POST /ai/knowledge/{project}/reindex?batch_size=32`.
- Reindex is best-effort and preserves lexical fallback on provider failure.
- Existing FTS5 re-ingestion fix preserved.
- CI remains deterministic: no external embedding provider is required by tests.

## Validation
- Python tests: 44 passed.
- Python compileall: passed.
- C++ Release CMake build: passed.
- API version validation: `0.12.0-b4`.

## Remaining before stable
Run B4 against a real embedding model and compare Hit@1, Hit@3, MRR, false-positive rate, out-of-context rejection, and latency.
