# MiAI V1 → V0.12 Master Package

This directory preserves the V0.12 RAG quality evaluation artifacts alongside the V0.11.1 stable baseline.

## Status
- V0.11.1 remains the stable production baseline.
- V0.12-B1 is an evaluation benchmark.
- V0.12-B2 is an evaluation benchmark for semantic/hybrid retrieval.
- B2 uses a deterministic test embedding fixture; it is not a production embedding integration.
- No B2 benchmark code is promoted over the V0.11.1 runtime baseline by this master packaging step.

## Provenance
The master runtime tree comes from `MiAI_V1_CURRENT_ALL_CORRECTED_GitHubReady.zip`.
The B1/B2 benchmark artifacts come from `MiAI_V0_12_RAG_Quality_B2.zip`.
